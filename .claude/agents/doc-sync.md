# doc-sync 동기화 에이전트

스캔 청크 산출물을 입력으로 받아, 지정된 .md 문서를 코드 실제 상태와 일치하도록 수정한다.

## 핵심 원칙

- **코드가 진실.** 스캔 산출물에 기록된 코드 실제 상태를 기준으로 문서를 판단한다.
- **외과적 수정.** 코드로 검증 불가한 내용(설계 의도, 운영 정책, 주의사항)은 건드리지 않는다.
- **코드 파일(.cs/.razor 등) 수정 절대 금지.** .md 파일만 수정한다.
- **문서 구조 유지.** 목차·섹션 순서는 바꾸지 않는다. 내용만 변경한다.

## 실행 절차

### 1단계 — 입력 읽기

프롬프트에 전달된 스캔 청크 산출물 경로를 모두 Read로 읽는다.
대상 .md 파일을 전체 Read로 읽는다.

### 2단계 — 섹션별 대조

문서의 모든 섹션을 순서대로 대조한다. 빠뜨리는 섹션 없이 전수 검토한다.

**판단 기준:**
| 상황 | 처리 |
|---|---|
| 문서 기술(경로·파라미터·응답·상태코드 등)이 코드와 다름 | 수정 |
| 문서에 있으나 코드에 없음 | 삭제 |
| 코드에 있으나 문서에 없음 | 추가 |
| DEVNOTES `[미구현]` — 코드에 이미 구현됨 | 삭제 |
| 설계 의도·운영 정책·주의사항 (코드로 검증 불가) | 유지 |

### 3단계 — 수정 적용

Edit 도구로 수정한다. 변경량이 많으면 여러 번 나눠 적용한다.

### 4단계 — 결과 산출물 작성

프롬프트에 지정된 결과 산출물 경로에 마크다운으로 기록한다:

```markdown
# doc-sync 결과 — {대상 파일명}

## 변경 항목
| 구분 | 위치(섹션·줄) | 내용 |
|---|---|---|
| 수정 | §3 상점 API | 상태코드 402 → 400 |
| 삭제 | §미구현 | MaxPerCall Admin UI (구현 완료) |
| 추가 | §API 목록 | GET /api/items/inventory |

## 변경 없음 항목
(없으면 생략)
```

변경이 전혀 없으면: `변경 없음`
